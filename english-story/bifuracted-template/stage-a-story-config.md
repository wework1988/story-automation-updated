ENGLISH STORYBOARD PIPELINE — STORY DOCTOR VERSION
For English YouTube Documentary / 2D Animation / Military / Crime / Geopolitical / Intelligence Stories
================================================================================

CHANNEL NAME:
Story Doctor

PURPOSE

This pipeline converts a completed English documentary story into a full visual storyboard for 2D animation.

It is designed for English-speaking audiences in the USA, UK, Australia, Canada, and similar markets.

The pipeline must preserve a hard-hitting, cinematic, suspense-driven documentary tone while keeping visual prompts historically grounded, character-consistent, and production-ready.

The production flow is:

FULL STORY
↓
STAGE A — STORY CONFIG ENGINE
↓
STAGE B — 5-SECOND SCENE BREAKDOWN ENGINE
↓
STAGE C — IMAGE + MOTION PROMPT ENGINE

The final goal is to create:
- a complete story configuration,
- a locked 5-second scene breakdown,
- consistent character-controlled image prompts,
- detailed but restrained motion prompts,
- historically grounded 2D animated documentary visuals.

================================================================================
GLOBAL ENGLISH STORYTELLING STYLE
================================================================================

The English story must feel like a premium YouTube documentary.

It must NOT feel like:
- a Hindi script translated into English
- a school essay
- a Wikipedia summary
- a flat news report
- a bullet-point explainer
- a soft documentary
- a generic AI script
- an overdramatic fake thriller
- a list of facts
- a chapter-wise report

The tone must be:

Cold.
Sharp.
Visual.
Tense.
Clear.
Serious.
Cinematic.
Fact-driven.
Emotionally controlled.
Built around danger, pressure, timing, consequence, and human decision.

Use English documentary rhythm:

Long explanation.
Short punch.
Visual detail.
Then a twist.

Example style:

“On paper, the mission looked simple. Get in, capture the target, and leave before anyone understood what had happened.

But that was the dangerous part.

Because once the first team moved, there would be no clean way back.”

Use natural English documentary phrases like:

“To understand why this mattered, you have to look at the map.”

“The real problem was not the target. It was the distance.”

“On paper, the plan looked simple.”

“But in the real world, nothing about this was simple.”

“What happened next exposed a much bigger weakness.”

“This was not just an operation. It was a message.”

“By the time the dust settled, one thing was clear.”

Real public-figure names may appear ONLY inside the original English line if the source story already contains the name.

- initials that clearly identify them
- exact likeness instructions
- readable nameplates
- readable party symbols

CHARACTER LIBRARY SYSTEM
================================================================================

If CHARACTER_LIBRARY is supplied, it is authoritative for recurring character consistency.

Each character block may contain:

NEGATIVE IDENTITY FIREWALL — traits to avoid.
Optional variants such as age, era, wardrobe, or context variations.

Stage A must scan FULL_STORY and match recurring characters against CHARACTER_LIBRARY.

Stage B must propagate the correct Library lock ID into every scene where that locked character appears, is referenced, is implied, or is represented.

Stage C must resolve the Library lock ID by copying the matching LOCKED CHARACTER ANCHOR verbatim into the IMAGE PROMPT.

The neutral ID itself must never appear in the image prompt body.

CHARACTER LIBRARY AMBIGUITY RULE
================================================================================

If a character clearly matches one library entry, mark it as LIBRARY-LOCKED.

Record it under:

Ambiguous / unmatched:
[description]

Stage B and Stage C must not invent a lock that Stage A could not safely establish.

If a recurring character has no library entry, fall back to origin, role, era, and story-context inference.

Do not invent new character IDs.

================================================================================
HOSTILE ACTOR VISUAL MENACE RULE
================================================================================

A hostile actor means:
terrorist, extremist, radical handler, hostile recruiter, radical propagandist, violent conspirator, terror commander, criminal operative, handler, suspect linked to hostile activity, or hostile network member.

Apply hostile coding only when the story identifies the person or group as hostile, criminal, extremist, militant, handler, operative, propagandist, or suspect linked to hostile activity.

Do NOT apply hostile coding only because of:
religion, ethnicity, country, beard, skullcap, shalwar kameez, hijab, mosque background, regional dress, or nationality.

Ordinary civilians must remain ordinary civilians.

When hostile actors appear, they must visually read as dangerous within 1–2 seconds.

Do NOT make hostile actors look:
- soft
- friendly
- innocent
- gentle
- sympathetic
- warm
- calm in a peaceful way
- ordinary
- harmless
- saintly
- like a regular civilian
- like a friendly shopkeeper
- like a humble teacher
- like a gentle uncle

Hostile actors must include:
- hardened face
- weathered skin
- tense jaw
- narrowed or shadowed eyes
- guarded posture
- secretive body language
- directional menace lighting
- rough or practical clothing linked to the story setting
- suspicious or operational object if appropriate

If a hostile actor appears as main subject or co-subject in Stage C, the Foreground section must open with a hostile staging description before any environment detail.

================================================================================
FACTUAL SAFETY RULE
================================================================================

Use only facts provided in the full story, transcript, notes, or reliable source material provided by the user.

Do NOT invent:
- names
- dates
- deaths
- numbers
- places
- secret meetings
- private conversations
- official decisions
- military operations
- intelligence claims
- conspiracy claims
- assassination plots
- criminal allegations

If a claim is uncertain, disputed, alleged, or based on reports, phrase carefully.

Use language like:

“According to reports…”
“Officials later said…”
“The claim has been disputed…”
“Some accounts suggest…”
“The story says…”
“It is alleged that…”
“Public records show…”
“What is known is this…”

Do not present uncertain claims as confirmed truth.

If the source contains contradictions, do not choose one as fact unless clearly supported.

Write:

“Different accounts give different details, but the core of the story is this…”

Strong does not mean careless.
Sharp does not mean false.
